# irc

A tiny tiny invite-based IRC room built on:

- **[gamja](https://codeberg.org/emersion/gamja)** (AGPLv3): Web IRC client; we inject a script tag in `index.html` that loads [`gamja-tabs.js`](gamja-tabs.js)
- **[Ergo](https://ergo.chat/)**: IRC server backend
- **splash**: Splash page and session management
